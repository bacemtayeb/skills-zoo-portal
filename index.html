Methodology Summary

Our dataset is compiled from open-source agent libraries and marketplace snapshots. It consists of two primary components:

137k Snapshot

Full corpus metadata and execution statistics across benign and flagged agent capabilities.

238 Labeled Skills

Human-reviewed subset with attention span annotations. Each entry includes source marketplace, vulnerability classification, top-5 suspicious spans ranked by attention score, and dual-reviewer ground truth labels (131 HARMFUL, 80 BENIGN_OFFENSIVE, 27 BENIGN false alarms). Reviewer agreement: κ=0.466 on binary malicious/benign classification.
